### Quality Engineering & Root-Cause Analysis Toolkit

A professional toolkit containing engineering templates and automation scripts designed to streamline quality compliance, accelerate root-cause analysis, and optimize continuous improvement processes. 

### 🛠️ Included Tools

* **Python Analytical Scripts**: Automates the statistical processing of defect data to eliminate manual charting errors.
* **Automated FMEA Template**: Excel framework utilizing dynamic weighting to identify critical process failure modes.
* **CAPA & 5-Why Framework**: Standardized documentation workflow for tracing systemic issues back to root causes.
